BareBlog v0.2.0: Adding cleanup, color and movement to blog themes

2026-10-23 comments
  • BareBlog
  • release
  • color
  • animation

BareBlog v0.2.0 has just been released. It contains a few handy tools and visual possibilities to set. Let's start with the visual possibilities. You can set any of these options in your blog.edn file.

  • :navbar-colors lets the colours of the theme drift behind the navbar
  • :page-colors sets similar colors still behind the whole page
  • :gradient-titles fills the titles of posts and pages, with a gradient of the colours of the theme. The title of a post moves its gradient once as the page opens.

The idea of these options is that it ads both color and movement to your blog, making it more alive. To further support this each blog post now has a line at the top of the page that grows wider as you scroll down the blog post.

Next to each blog post is now a content view that shows all headings, and marks where you are reading now. You can also use it to quickly navigate to a different part of the blog post.

Finally, on the presentation side post title font sizes are slightly increased.

All of these changes are meant to (optionally) add color and animation to a blog. You can see these features implemented in my own blog. I created them in the first place, because I like them.

I've also noticed that my use of tags was a bit random, for example I used ClojureScript and Clojurescript, which end up becoming two different tags even though they point to the same thing. To aide in that I've added a few command line tools to help clean up tags. Run bareblog help to see the possibilities. The commands specifically for tags are:

bareblog tags ;; every tag, and each written in more than one way bareblog tags rename old "new" ;; a tag, in every post and page --yes ;; with a yes to the question

I hope these options are helpful. Enjoy!
